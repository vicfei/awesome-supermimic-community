# Contributing

PRs welcome. Guidelines:

1. One link per bullet, with a one-line note on what it is and why it matters.
2. Deep-dive readings: include language tag ([zh] / [en] / ...) in the bullet.
3. Reproduction tracker rows must carry verifiable status evidence (repo link, issue, or post);
   update the row when status changes rather than adding duplicates.
4. Star counts, if cited, are snapshots — note the date.
5. This is a supplement to the primary list (DiaoOrg/awesome-supermimic) — if your link belongs
   there (an implementation/extension/demo of SuperMimic itself), PR there instead or as well.
6. No attribution watermarks; plain, direct prose.
